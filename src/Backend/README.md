# GoACARS Backend API

ASP.NET Core backend with SignalR for real-time updates.

## Responsibilities

- Authentication (JWT + refresh tokens)
- Receive and store flight telemetry
- Calculate statistics
- Live WebSocket updates via SignalR
- Admin API endpoints
- Rate limiting, audit logs, security

## Tech

- ASP.NET Core
- SignalR
- Entity Framework Core
- PostgreSQL
- Redis
