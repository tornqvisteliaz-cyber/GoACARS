# GoACARS Desktop Client

Windows Desktop application (WPF) and optional Windows Service.

## Responsibilities

- Connect to Microsoft SimConnect
- Detect aircraft and flight state
- Send live telemetry
- Detect takeoff / landing / shutdown
- Upload completed flight reports
- Handle reconnections gracefully

## Tech

- C# / .NET
- WPF
- Microsoft SimConnect SDK
